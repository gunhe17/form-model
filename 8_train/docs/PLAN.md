# 1단계 검출기 재구성 계획 (2026-09-09)

1차·2차 학습과 실서식 정정(4_replica, GT 999)까지의 결론을 바탕으로, 데이터셋을 다시 만들어 1단계 검출기를 학습한다.

## 0. 결론과 의도

**한 문장**: 검출기에게 "찾기"만 시키고 "판단"은 2단계로 넘긴다. 데이터는 자연 분포를 유지한 채 클래스별 하한을 채우고, 보충은 측정된 실패에만 한다.

| 결정 | 내용 | 근거 |
|---|---|---|
| 클래스 = 생김새 8종 | marker · comb · cell · gap · underline · placeholder · signature · photo. 글자 택일(word)·괘선 없는 영역(area)은 1단계 제외 | 다섯 기준 K1~K5 검토판. 검출기는 국소 픽셀만 보므로 뜻(11종)은 못 가르고 모양은 가른다 (radio 176 중 106을 checkbox로, 마커 98~100%) |
| 의미 11종은 병행 라벨로 유지 | 필드마다 (모양, 뜻) 두 라벨. 2단계 학습 데이터 | 2단계는 후보마다 "입력 아님 / 11종" 선택 |
| 분포: 균일 X, 자연 분포 + 하한 | 어느 클래스도 5% 미만·35% 초과 금지. 문맥(페이지당 photo 0~2, signature 0~3)은 자연스럽게 | CommonForms: 자연 분포에서 가장 드문 Signature가 AP 93.5로 최고. RFS(LVIS) 방식이 롱테일 표준이며 build_skeleton의 IRFS 부스트가 이미 그것 |
| 보충 = 측정된 실패에만 | cgf 높이 41px대, cg 폭 180px대, gp 폭 100px대, opt·circ·dbx·stamp 부재, 페이지 밀도 45→22 | diag_style: cell 채움 45%/2%, gap 56%. 실패는 개수가 아니라 치수·문맥 분포 밖 |
| 다양성이 개수보다 먼저 | 클래스 × 치수 × 문맥 격자에서 실서식이 있는 칸을 학습이 모두 덮게 | DocSynth-300K가 최적화한 것은 클래스 비율이 아니라 레이아웃 다양성. SAHI·LMM-Det: 약한 조건의 노출을 늘려 recall 회복 |
| 클린+열화 한 풀로 처음부터 | 2차처럼 순서대로 배우다 한 축을 잃는 일 방지 | 2차: stress 55→99.9 이지만 cgf −21.8pt |
| 측정은 실서식이 1차 지표 | 에폭마다 실서식 44(→149)와 stress 500 채점, 홀드아웃은 best.pt 선택용 | 1차에서 홀드아웃만 보다 실물 격차를 5에폭까지 몰랐음 |

## 1. 클래스 정의와 라벨 규칙

검출 클래스는 렌더된 마크업 서명으로 정한다(검토판 규칙 R1~R15, `8_train/label_stage1.py`).

| 클래스 | 생김새 | 박스 규약 |
|---|---|---|
| marker | □ [ ] ( ) ①~⑩ 글리프, 또는 테두리 있는 빈 정사각 하나 | 글리프 박스 |
| comb | 테두리 있는 소형 정사각(≤30px)이 같은 크기로 2개 이상 인접 | 낱칸 각각 |
| cell | 괘선(실선·점선·굵은선)으로 둘러싸인 빈 영역. 척도표 선택지 셀 포함 | 셀에 필드 하나뿐이고 인쇄 글자 없으면 셀 안쪽. 아니면 요소 박스 |
| gap | 표시 없는 글줄 속 빈 자리, 표 안 소형 슬롯 | 요소 박스 |
| underline | 밑줄 위 빈 자리 | 선 포함 박스 |
| placeholder | 덮어쓸 인쇄 글자(○○○·20○○·예시문·※·원형 ○) | 인쇄물 포함 |
| signature | (인)·(서명 또는 인)·(직인) 문구, 직인 박스, 도장 칸 | 문구 박스 |
| photo | "사 진" 인쇄 세로 박스, 원형 변형 | 박스 |
| (제외) word | 인쇄 단어 택일 | 2단계에서 OCR 단어로 |
| (제외) area | 괘선 없는 큰 영역 | 구조 후보로 |

## 2. 목표 분포

| 클래스 | 현재 | 목표 | 페이지당 문맥 | 채우는 수단 |
|---|---|---|---|---|
| cell | 69% | 35% | 표 있는 페이지 5~40 | 격자 행·열 축소, 높이 22~60 분산 |
| gap | 8.5% | 22% | 문장·표 안 3~15 | text_prose·text_colon 빈도↑, 폭 24~220 분산 |
| marker | 6% | 15% | 그룹 2~15 | □ radio 그룹 추가(현재 radio의 83%가 글자형) |
| comb | 0.7% | 7% | 주민번호·우편번호·날짜 0~3묶음 | comb_slot 가중치↑, run 2~13, 점선 변형 |
| placeholder | 1.7% | 6% | 0~6 | pf_* 허용 유형 확대, ○○○ 문장 삽입 |
| signature | 1.3% | 5% | 0~3 | 서명줄·직인 카드 유지, 등록카드·계약서 쿼터↑ |
| underline | 0.7% | 5% | 0~8 | text_ul·num_both·sig_ul 가중치↑ |
| photo | 0.1% | 5% | 0~2 | img_cell·img_card 가중치↑, 원형 변형 추가, 등록카드·증서 쿼터↑ |

**부품 집중 페이지 10%**(2,000장): 카탈로그식으로 한 클래스의 변형을 빽빽하게 배치. 드문 클래스의 절대 수와 치수 변화폭을 채우고 나머지 90%가 문맥을 지킨다.
**음성**: 빈 페이지 6% 유지 + 값 인쇄 셀·머리글·안내문 밑줄을 페이지당 1~4개.
**밀도**: 페이지당 필드 15~50, 중앙값 25.

## 3. 단계와 합격 기준

| 단계 | 작업 | 산출 | 합격 |
|---|---|---|---|
| P0 측정 | `label_stage1.py`로 학습 20,000 + 실서식 44에 8종 라벨 부여, 클래스 × 치수 × 문맥 격자 | 커버리지 표 | 실서식이 있는 격자 칸 중 학습이 비어 있는 칸 목록 확정 |
| P1 생성기 | 2절 수단 구현: 카드 가중치·쿼터·치수 범위·신규 부품(opt·circ·dbx·stamp·open_table·inset_label_full)·부품 집중 페이지 | 3_generator 수정, 20,000장 재렌더, **검수 아티팩트** | P0 격자의 빈 칸 0, 클래스 점유율 5~35%, 밀도 중앙값 25±5, **사용자 검수 통과(필수)** |
| P2 증강 | 재렌더본에 7_augment build_pool 그대로 (clean+swap+office+degraded) | 풀 62,000 + stress 500 | 구분별 장수 일치 |
| P3 학습 | `to_yolo.py --stage1` 로 8종 라벨(word·area 제외) → FFDNet-L → 8종 헤드, imgsz 1600, batch 4, 클린+열화 한 풀, 6 에폭, 에폭마다 실서식·stress 채점 | last_eN.pt | 실서식 후보 recall(conf 0.05) ≥ 95, stress ≥ 98, 홀드아웃 ≥ 99.5 |
| P4 진단 | diag_style --compare(재구성 전후), 클래스별 실서식 recall | 표 | 클래스별 recall 편차 < 15pt |
| P5 앵커 확장 | 4_replica 44 → 149 (lint 통과 조건) | 전사 | lint 위반 0 |

중단 규칙(P3): 실서식 recall 2에폭 연속 +1pt 미만 → 종료. 홀드아웃 < 99.0 → 직전 가중치.
