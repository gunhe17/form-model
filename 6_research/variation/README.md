## 넷이 일치하는 결론

1. **합성 검증 점수는 실성능의 예측자가 아니다.** 합성 valid 99.8 / 실 10.8(Horváth 2208.04171), YOLOv11 합성 0.98 / 실 0.88(2509.15045)이 우리 99.9/90.4의 극단형. 체크포인트 선택·조기 종료·폭 조절의 **판정은 실서식만**으로. Ultralytics `best.pt`/`patience` 가 합성 val 을 보는 한 e1 정점을 잡을 수 없다(C).
2. **폭 > 사실성 > 수량.** Tremblay 절제(1804.06516): 텍스처 풀 8K→4K 만으로 −2.2 AP; Alghonaim(2011.07112) "고품질 소량 > 저품질 대량"; Movshovitz-Attias "저품질을 늘리면 악화". 우리 이산 3~6값 축은 "풀 크기 3~6"이라 가장 취약한 설정. **모든 축을 연속 구간으로**(SynthDoG config_ko 가 전 축 구간형).
3. **글꼴 가짓수가 문서·텍스트 합성기 간 가장 일관된 차이.** SynthText 1,200 · SynthTIGER 3,568 · Dessurt 10,000+ vs 우리 3. DDR(2105.14931): 스타일 불일치 −6~9 mAP, 혼합이 단일보다 우수.
4. **구조 문법은 옳다(SDR 1810.10093: 구조 유지 + 그 위 전부 랜덤이 200k 무작위보다 25k 로 우수). 단 순수 무작위 배치는 무효(DocSynth-300K 80.5→80.5).** 부족한 것은 문법 위의 **전역 연속 파라미터**(간격·열 폭·행 높이·여백)와 **비대상 방해물**(도장·로고·안내문; Eversberg 0.653→0.669, Tremblay −1.1).
5. **어휘는 실코퍼스에서 주입한다**(Dessurt·RIDGE·SynthText 팔레트). 의미의 고충실은 불필요, 분포(길이·빈도)가 실서식을 덮으면 된다(DDR).
6. **실데이터 소량 혼합이 가장 재현성 있는 처방.** 합성 사전학습 → 실 10% 미세조정이 실 100% 에 근접·초과(Nowruzi 1907.07061, Dwibedi 1708.01642); 미세조정 vs 혼합은 유의차 없음(Burdorf 2202.00632, 5시드) → 둘 다 돌려 실 val 로 고른다. 실 100장 규모는 head-only 미세조정이 안전(TFA 2003.06957).
7. **44장으로는 +2pt 를 못 잰다.** 페이지 군집 설계효과 2~5 → 95% CI ±2.7~4.2pt(D 계산). 짝지은 페이지 부트스트랩으로 +2pt 검출에 125~440장. 앵커 확장(P5)은 개선의 전제이며, **원천 PDF 단위**로 학습/평가를 나눠야 템플릿 기억 누수를 막는다.
8. **적응형 폭.** ADR(1910.07113): 엔트로피↑ ⇒ 실오차↓·시뮬 오차↑; DORAEMON(2311.01885): 과도 랜덤화는 보수적 모델 → "성공 제약(lint·최소 크기) 하에서 실서식 recall 이 안 떨어지는 한 폭 확장".

## 우리 계획에 반영 (PLAN.md 10절 P6)

- 측정 먼저: score.py 에 페이지 군집 부트스트랩 CI, 에폭별 합성/실 확신도 AUROC, backbone 크롭 임베딩 PRDC coverage(클래스별).
- 앵커 44→149 전사(P5), 원천 PDF 단위 분할 100/49.
- 생성기 v4 "폭": 연속 테마축, 글꼴 ≥30, OCR 어휘 주입, 방해물, DPR/zoom, 배치 지터를 실서식 히스토그램에 정렬, (후순위) 실요소 풀 + BestFit.
- 학습 v4: val=실서식, fliplr 0·hsv 0, mosaic 0.5 + close_mosaic 30%, scale (0.7,1.6), degrees 2, freeze 10 + AdamW 1e-3, patience 5; 이어서 실 100장 미세조정(head-only vs full lr/10, 합성 리플레이 20~30%) vs 혼합(실 5~20% 오버샘플).
- 축 절제(2k 렌더 × 축 on/off)는 예산이 남을 때.
